# Web UI 运行说明

## 1. 页面结构

新版页面是单页双标签结构：

- `问答助手`：面向最终用户，负责提问、查看回答和证据卡片
- `知识库管理`：面向调试与运维，负责初始化、构建索引、删除索引和调试提问

## 2. 初始化

在任一标签页顶部输入配置文件路径并选择 `[milvus|pipeline]` 方案，然后点击 `初始化`。

- 默认配置路径为 `cfgs/config.yaml`
- 第一次初始化可能需要下载模型，耗时会比较长
- 初始化完成后，页面状态栏会显示当前模式

如果初始化失败，页面会直接显示错误信息，不需要再去终端里找输出。

## 3. 问答助手

在 `问答助手` 标签页中：

1. 输入问题
2. 可选勾选 `显示调试信息`
3. 点击 `提交问题`

页面会返回 3 类内容：

- 最终回答
- 证据卡片：展示命中的书名、原文片段、文件名和分数
- 调试信息：启用时显示检索计数和模式等结构化摘要

如果尚未初始化，页面会提示先完成初始化。

## 4. 知识库管理

`知识库管理` 标签页保留完整管理能力：

- 初始化
- 构建索引
- 删除索引
- 调试提问

### 构建索引

在 `文件或目录路径` 中输入本地语料路径，例如：

- `./data/history_24/baihuasanguozhi.txt`
- `./data/history_24/`

然后根据需要选择是否 `覆盖已有索引`，点击 `构建索引`。

### 删除索引

输入要删除的文件路径，然后点击 `删除索引`。页面会回显删除结果；如果底层执行器返回计数，也会显示删除条数和剩余条数。

### 调试提问

输入问题后点击 `调试提问`，页面会展示：

- 回答结果
- 查询状态
- 检索调试信息

这个区域适合开发调试和演示，不建议替代正常问答页使用。
